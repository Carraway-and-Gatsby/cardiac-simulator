# 개발용 도식 자산

외부 모델·텍스처·환자 데이터 없이 이 프로젝트의 JSON과 bpy 스크립트로 생성한 구체 네 개입니다.
다운로드한 제3자 해부학 자산이 없으므로 적용할 외부 모델 라이선스도 없습니다.
현재 사용 범위는 프로젝트 내부 개발입니다. `LicenseRef-Project-Internal`은 SPDX 표준 라이선스가 아니라
내부 관리용 식별자입니다. 프로젝트 소유자의 공개 배포 라이선스 결정과 검토 전에는 재배포 승인으로 해석하지 않습니다.

이 기록은 시각적 형태의 의학적 정확성이나 독점적 권리를 보증하지 않습니다.

# 해부학적 정확성과 라이선스 검수

## 2026-10-23 공개 데모 범위 추가

사용자가 설치 없이 접속하는 GitHub 기반 오픈소스 공개 데모를 명시적으로 요청했습니다.
이에 따라 **미검수 상태를 명시한 소프트웨어 시연**을 GitHub Pages로 제공하는 범위를 추가합니다.
이 결정은 아래의 전문가 검수 완료 릴리스 승인과 구분하며, 승인 필드·검수자·검수 해시를 채우지 않습니다.
`verify:release`는 계속 실패해야 합니다. manifest의 기존 `internal-only` / `unreviewed`는
미완료 승인 기록으로 유지하며, 공개 데모가 비공개라는 뜻으로 사용하지 않습니다.

데모는 CC BY 4.0 HRA 원본의 고정 해시를 확인하고 Blender 4.5 LTS로 생성한 HRA GLB를
출처·저작자·라이선스·변경 고지와 함께 별도 Pages 산출물로 제공합니다. GLB와 `.blend`는 Git에
커밋하지 않으며, 원본 다운로드·기존 도식·절차적 초안·개인 설정은 웹 산출물에서 제외합니다.
해부학적으로 승인된 학습 자료나 임상적으로 검증된 시뮬레이터를 제공한다고 표현하지 않습니다.
이 공개 범위와 전문가 검수의 구분은 [공개 안내](public-source-release.md)에 기록합니다.
아래의 기존 해부학 판정과 남은 검수 항목은 변경하지 않습니다.

## 해부학 검수 판정

2026-10-23에 Human Reference Atlas(HRA)의 **남성 심장 v1.3와 남성 혈관 v1.3 원본 GLB를 확보**하고,
같은 아틀라스 좌표의 심장 14개·혈관 30개, 총 **44개 구조**를 선택했습니다. 기존 외피·네 방·13개
혈관의 절차적 초안과 네 구체 도식도 보존합니다. 모든 자산은 **해부학 검수 미완료**입니다.
기존 `internal-only` 승인 기록은 유지하며, HRA 공개 데모의 사용 범위만 위의 명시적 요청에 따라 추가합니다.

HRA는 Visible Human 기반 참조 아틀라스 재구성이며, 이번 프로젝트에서 직접 의료영상을 분할한
결과가 아닙니다. 성인 자료에 기반하지만 선택한 심장의 정상성·벽 두께·세부 판막 장치·관상동맥
우세형·원영상 대응은 검증되지 않았습니다. HRA 형상은 정적이며 측정된 심근 운동이 없습니다.
별도의 0D 생리 계산의 통과를 메시의 해부학·생리학 검증으로 해석하지 않습니다. 기존 초안의
용적 기반 상대 축척은 실제 심근 변형이 아닙니다. 미검수 색·공간 관계·두께·크기를 승인된 학습
자료로 사용하지 않습니다.
AI, bpy, mesh 검사를 통과했다는 이유만으로 해부학적으로 정확하다고 보증할 수 없습니다.

출처별 선택·접근 조건은 [해부학 데이터셋 조사](anatomical-datasets.md), 구조별 미확인 사항·좌표
추론·원본 결함은 [해부학 검증 기록](ANATOMICAL_VALIDATION.md)에 기록합니다. **외부 원본을
확보한 사실과 프로젝트 결과를 승인한 사실은 다릅니다. 현재 전문가 검수와 검수 완료 릴리스 승인은 없습니다.**

## HRA 원본 권리와 변경 기록

HRA 두 원본은 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)을 명시합니다.
원본 제작자는 Kristen Browne 및 혈관의 Heidi Schlehlein이며, 데이터셋 인용 문구는 두 저자를
표기합니다. 출처·저작자·라이선스 링크·변경 사실을 유지해야 하며 원저작자의 보증을 암시하지 않습니다.

원본 제작·검수자 표기는 출처 정보입니다. 이 프로젝트의 부분 선택·변환·재질·사용 범위를 승인한
전문가로 기록하지 않습니다. GLB 처리 과정의 변경과 최종 해시는 별도로 검증하며, 일반적인
평활화·재메시·분기 추가·형태 창작으로 출처 형상을 대체하지 않습니다.
Blender import의 동일 vertex-index 중복 면 **18개(RA 12, LM 5, SVC 1)** 자동 제거도 변경 사항입니다.
좌표 변경 없이 각 중복 그룹에서 원본 방향 하나만 유지하는 제한된 처리이며, 비중복 표면은
보존합니다. 모든 원본 삼각형의 개수까지 유지했다고 주장하지 않습니다. 상세 비교·최종 집계는
[기하 검증 기록](ANATOMICAL_VALIDATION.md#5-기하-검사와-보존-정책)에 기록합니다.

UMN Heart0141은 CC BY-NC 4.0의 성인 조직 후보이지만 공식 다운로드가 인증을 요구하여 메시를
확보하지 못했습니다. 공개 metadata만 보존했습니다. UMN의 비상업 조건이나 CAP의 개별 데이터
계약을 HRA와 혼용하지 않습니다. HRA 원본 권리가 명확하더라도 프로젝트의 검수 완료 릴리스·해부학
검수 게이트는 아래 절차가 끝날 때까지 `internal-only` / `unreviewed`로 유지합니다.

## 실제 모델 도입·갱신 시 필수 기록

각 자산마다 manifest와 증거 문서에 아래 사항을 남깁니다.

- 출처 URL, 원저작자, 자산/버전 ID, 다운로드 날짜, 원본 파일 SHA-256.
- 라이선스 전문 또는 보존된 증거, 상업/교육 이용 및 수정·재배포 가능 범위, attribution 문구.
- NC/ND/SA 조건, 서비스 이용약관, 별도 텍스처·폰트·재질·파생 모델의 권리.
- 어떤 수정을 했는지와 최종 GLB 해시. `.blend`가 아닌 웹 공개 GLB 자체의 재배포 권한.
- 환자 데이터 기반이면 비식별화·동의·접근 권한 확인. 이 저장소에는 실제 환자 자료를 넣지 않습니다.

단순히 Sketchfab에서 다운로드 가능하거나 교육 목적이라는 사실만으로 사용 권리가 생기지 않습니다.
라이선스가 불명확하면 자산을 공개 디렉터리로 복사하지 않습니다. 소유자/권리 담당자가 판단합니다.

## 해부학 검수 절차

심장 해부학에 적격한 임상의 또는 해부학 전문가가, 버전과 사용 권한을 명시한 기준 자료와 비교합니다.
리뷰 문서에는 검토 대상 해시, 검수자, 자격/역할, 날짜, 참고 자료, 관찰한 오류와 수정 내역, 사용 범위를 기록합니다.

- 환자 기준 좌/우와 전/후·상/하, 단위·척도·심장 축을 명시합니다. 화면 좌우와 해부학 좌우를 혼동하지 않습니다.
- 심방·심실, 중격·벽의 연결 관계와 내외부 표면, 판막과 유입/유출로, 대혈관·관상혈관을 해당 범위 내에서 확인합니다.
- 여러 각도·절단면에서 누락, 비정상 연결, 면 뒤집힘, 간섭을 점검합니다. mesh topology 검사는 의학 검수를 대체하지 않습니다.
- 표시 이름과 선택 영역이 일치하는지, 투명도나 절단으로 실제 없는 연결이 생긴 것처럼 보이지 않는지 확인합니다.
- 박동·판막 애니메이션은 형태와 타이밍을 별도로 검수합니다. 압력·유량·ECG 등 생리 모델은 방정식·단위·참고 범위와 독립 검증이 필요합니다.
- 정상 변이, 생략한 구조, 적용 대상과 부적합한 용도를 화면에 표시합니다.

승인된 모델이라도 범위를 한정한 검수 기록이지 모든 사용에 대한 무조건적 정확성 보증은 아닙니다.

## 배포 게이트

자산 파일을 바꾸면 해시 및 해당 검수 증거를 갱신합니다. 기존 검수는 새 형상에 자동 승계하지 않습니다.
검수 완료 릴리스용 자산은 `licenseReview: approved-for-distribution`, `anatomyReview: approved`, 검수자·날짜·증거 경로와 현재 해시와 일치하는 `reviewedSha256`이 필요합니다.
전문가가 실제로 승인하기 전에는 이 값을 채우지 않습니다. `npm run verify:release`는 현재 실패해야 합니다.
검수 완료 릴리스의 배포 자동화에는 이 명령을 필수 단계로 연결해야 합니다.
별도 Pages 자동화는 위에서 명시한 미검수 공개 데모의 범위에 한정하며, 이 게이트를 통과한
승인 릴리스로 간주하지 않습니다.

앱 라이브러리의 라이선스와 3D 모델의 권리는 별개입니다. 이번 npm 직접/전이 의존성 라이선스는
`docs/dependency-licenses.json`에 설치본 기준으로 기록합니다. 공개 배포 전에는 패키지에 포함된 라이선스 전문과
번들에 포함되는 하위 자산의 고지 의무를 검토합니다. 프로젝트 원본 코드·스크립트·테스트·번역·문서는 [MIT](../LICENSE)로 공개합니다. HRA 유래 자료와 의존성의 별도 라이선스는 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)를 따릅니다. 공개 저장소에는 미검수 다운로드·생성 GLB와 Blender 장면을 포함하지 않으며, 이 소스 공개가 자산의 검수 상태나 배포 승인 게이트를 변경하지 않습니다.

# Cardiac contraction and valve motion: scope and validation

작성일: 2026-10-23 (Asia/Seoul). 이 문서는 HRA 정적 아틀라스에 적용하는 교육용 심장·판막 움직임의 근거와 검수 범위를 기록한다. 0D 계산값을 움직임으로 표현하는 기능이며, 심근 역학·판막 조직 역학·환자별 운동을 검증한 문서가 아니다.

## 생리학적 표현 계약

심방과 심실의 수축 순서, 판막을 통과하는 방향, 판막 사이에 양측 통과 유량이 없는 구간을 기존 0D 계산과 일치시킨다. 판막이 혈액을 보내는 펌프인 것처럼 독립적으로 박동하거나, 네 판막이 같은 위상으로 열리도록 만들지 않는다. NHLBI의 설명은 심방의 박출 후 방실판막이 닫히고, 심실 박출 후 유출판막이 닫히는 순서를 뒷받침한다. 이 출처는 애니메이션의 각도·속도·변형량을 제공하지 않는다. [NHLBI: How the Heart Beats](https://www.nhlbi.nih.gov/health/heart/heart-beats)

| 구조 | 전방 흐름 | 정상적인 닫힘의 역할 | 표시 판막엽 수 |
| --- | --- | --- | ---: |
| 승모판 `MV` | LA → LV | LV → LA 역류 방지 | 2 |
| 삼첨판 `TV` | RA → RV | RV → RA 역류 방지 | 3 |
| 대동맥판 `AV` | LV → 대동맥 | 대동맥 → LV 역류 방지 | 3 |
| 폐동맥판 `PVvalve` | RV → 폐동맥 | 폐동맥 → RV 역류 방지 | 3 |

판막 위치·방향과 일반적인 판막엽 수는 [American Heart Association: Heart Valves and Circulation](https://www.heart.org/en/health-topics/heart-valve-problems-and-disease/about-heart-valves)을 근거로 한다. 정상 성인의 일반적인 판막 구성에 대한 설명이며, 이 HRA 원본에서 각 판엽을 분할·식별했다는 뜻이 아니다. 선천적 이엽성 대동맥판 등 변이는 구현하지 않는다.

좌심실은 박출 중 장축 길이와 횡단면이 변하고 비틀림과 이완 시 되감김을 보인다. 심근 운동은 단순한 전체 크기 증감보다 복잡하다. MRI 연구는 장축 단축, 원주 변형, 벽 두께 변화와 비틀림을 서로 구별해 측정한다. 따라서 이 기능의 표시 배율을 심근 strain이나 벽 두께 측정값으로 읽지 않는다. [Hollingsworth et al., 2012, American Journal of Physiology: Heart and Circulatory Physiology](https://pmc.ncbi.nlm.nih.gov/articles/PMC3322734/)

비틀림의 되감김은 심실 충만에 앞서 일어날 수 있으므로, 표시 비틀림을 용적 감소량 하나에만 고정하면 심실 용적이 작은 채로 유지되는 이완 초기에 잘못된 정지가 생긴다. 이 구현은 계산된 활성도를 별도의 표시 신호로 사용할 수 있으나, 활성도는 측정된 비틀림이 아니다. [Burns et al., 2009, JACC: Cardiovascular Imaging](https://doi.org/10.1016/j.jcmg.2009.01.015)

승모판 역류는 판막이 충분히 밀폐되지 않을 때 역방향 흐름이 생기는 표현으로 구분한다. 음수 유량의 절댓값을 정상 전방 개방으로 바꾸지 않는다. 실제 역류의 원인은 다양하므로 현재 시나리오만으로 탈출증, 건삭 파열 또는 특정 판엽 병변을 추가하지 않는다. 대동맥판 협착은 일반적으로 판막의 좁은 개방과 관련되지만, 기존 0D 모델은 유량 저항 증가만 계산한다. 따라서 이 기능에서 협착의 실측 개방 면적이나 석회화 형상을 추가하지 않는다. [NHLBI: Heart Valve Diseases — Types](https://www.nhlbi.nih.gov/health/heart-valve-diseases/types)

## 계산과 표현의 경계

- 기존 압력·용적·유량 방정식은 `src/simulation/engine.ts`에 남는다. 화면 변형이 새 유량이나 압력을 생성하지 않는다.
- 심장, 판막, 혈류 입자, 그래프와 수치는 `src/App.tsx`의 같은 기록 샘플을 사용한다. 벽시계나 별도 사인파로 심장과 판막을 구동하지 않는다.
- 판막 개폐는 해당 판막의 전방 유량과 연결한다. 네 판막은 각자의 신호를 사용하며, 정상 상태의 방실판막과 반월판막이 함께 열린다고 가정하지 않는다.
- 심실의 시각적 수축 범위는 한 주기 최대 용적에 대한 상대 용적 감소를 사용한다. 모든 실험을 각자 0–1 최고 수축으로 정규화해 수축력 저하의 차이를 지우지 않는다.
- HRA 자산은 정적이고 운동 리그와 판엽 분할을 제공하지 않는다. 움직이는 판엽은 개폐를 설명하기 위해 만든 별도의 교육용 기하학이다. 원본 판막의 보존과 이 재구성의 출처를 구분한다.
- 움직임 끄기는 원본 해부 형상으로 돌아가는 비교 기능이다. 원본 GLB를 덮어쓰거나, 재구성 판엽을 원본 44개 구조의 검증된 세부 해부학으로 등록하지 않는다.

HRA 형상과 0D 계산은 동일 피험자의 데이터가 아니다. 기준 아틀라스의 촬영·재구성 심장 주기는 확인되지 않았으므로 원본을 실제 이완말기 형상으로 확정하지 않는다. 계산 용적에 따른 표시 변형은 벽의 질량 보존, 심근 비압축성, 내강 용적 일치, 건삭 장력, 판엽 접촉·응력·관성을 보장하지 않는다. 이 한계는 [기존 해부학 검증](ANATOMICAL_VALIDATION.md), [생리 모델](physiology-model.md), [혈류 표현](blood-flow-validation.md)의 범위에 추가된다.

## 심장 변형 함수

`src/motion/cardiac-motion.ts`는 React·Three.js와 독립적인 순수 함수이다. `createMotionReference`는 기록 주기에서 각 심방·심실의 최대 계산 용적을 구한다. `evaluateCardiacMotion`은 선택 샘플에서 아래 여섯 가중치를 반환한다. 모든 비율 제한은 표시 변형에만 적용하며 생리 계산 결과를 수정하지 않는다.

```text
c_i = clamp(1 − V_i / V_i,max, 0, 1) × displayIntensity
w = [c_RA, c_LA, c_RV, c_LV,
     c_RV × sqrt(clamp(a_RV, 0, 1)),
     c_LV × sqrt(clamp(a_LV, 0, 1))]
```

`displayIntensity`는 0–1로 제한한다. 따라서 같은 표시 강도에서 좌심실 최대 수축 가중치는 그 시나리오의 계산 EF에 비례한다. HFrEF 시나리오의 작은 용적 변화를 기준 시나리오와 같은 진폭으로 확대하지 않는다. 마지막 두 가중치는 수축 가중치에 활성도를 곱한 교육용 비틀림 표현이며, 심실 용적이 동일해도 활성도가 떨어지면 되감김을 나타낼 수 있다. 실제 비틀림 시점이나 각도에 맞춘 추정은 아니다.

`motionBasis`는 원본 glTF의 metre/Y-up 좌표에서 여섯 상대 변형 벡터를 만든다. 각 챔버의 경계 상자와 추정 장축으로 만든 공간 가중치를 혼합해 하나의 연속적인 표시 변형장을 사용한다. 심장·관상혈관·가이드 메시에는 같은 원본 좌표에서 같은 변위 함수를 적용한다. 입자의 중심 경로도 이 함수를 적용한 표본 사이에서 보간하며, 경로 주변의 입자 분포 반경은 그래픽 값으로 유지한다. 입자의 모든 표면 점이나 실제 혈구 운동을 변형장에 맞춰 푸는 방식은 아니다. 이는 서로 다른 구조를 각자의 중심에서 독립 확대·축소해 접점이 벌어지는 문제를 줄이는 장치이며, 조직 결합이나 연속된 심근의 검증이 아니다.

원주 방향 계수는 심실 0.40·심방 0.28, 장축 방향 계수는 심실 0.14·심방 0.22이다. 심실 접선 변형의 기본 크기는 0.20에 추정 심첨 위치 비율을 곱한다. 좌심실 접선 부호는 심첨에서 기저를 바라볼 때 반시계방향이 되도록 정했다. 이 방향은 우세한 좌심실 수축기 비틀림의 방향을 반영하며, 초기 일시적 회전이나 심첨·기저의 전체 회전 이력을 재현하지 않는다. [Moon et al., 1994, Circulation](https://doi.org/10.1161/01.CIR.89.1.142)

단축 변위는 기저 벡터당 22 mm, 접선 변위는 3 mm로 제한한다. 모든 공간 가중치에 추가 표시 계수 0.7을 적용하여, 0–1 모션 가중치에서 합성 변위 상한은 17.5 mm이다. 이 숫자는 표시 범위를 정하기 위한 설계값이며, 정상 strain·정상 비틀림·실제 심첨 변위가 아니다. 우심실 접선 효과 또한 실측 우심실 회전으로 보정되지 않았다.

네 판막의 원본 경계 상자 내부는 고정하고, 바깥 24 mm 영역에서 변위를 부드럽게 증가시킨다. 이는 재구성 판막의 프레임과 인접 혈관근을 안정적으로 연결하기 위한 선택이다. 실제 판륜의 병진·회전·면적 변화나 수축기 판륜 하강을 재현하지 않는다. 원본 판막의 경계 상자는 검증된 판륜 윤곽도 아니다. 시각적 단축 방향만으로 정확한 심근 섬유 방향을 추정할 수 없다.

17³개의 공간 표본과 여섯 가중치의 0/1 조합 64개에서 유한차분 Jacobian 행렬식을 검사했다. 총 314,432개 조합에서 양의 행렬식이 확인되어, 검사 지점에서의 국소 뒤집힘은 검출되지 않았다. 이 검사는 연속 공간 전체의 보증, 모든 중간 가중치의 증명, 메시 자체 교차 검사, 조직 체적 보존 또는 해부학적 승인에 해당하지 않는다.

## 판막 재구성과 개폐 함수

`src/motion/valve-model.ts`는 기존 HRA 판막을 분할하는 대신 11개의 얇은 판엽 표면을 생성한다. 승모판의 두 판엽은 한 지름 방향에서 만나며, 삼첨판·대동맥판·폐동맥판의 세 판엽은 세 방사형 경계에서 만난다. 방실판막은 얕은 곡면, 반월판막은 상대적으로 깊은 주머니 곡면을 사용한다. 건삭, 조직 두께, 접촉력, 이엽성 대동맥판 또는 판엽별 실제 치수는 포함하지 않는다.

판륜의 중심은 해당 원본 구조 경계의 중심에 두고, 앞뒤 혈류 가이드 점을 잇는 방향을 개방 방향으로 사용한다. 타원 반경은 움직이는 판엽 전체가 원본 구조의 경계 상자에 들어가도록 보수적으로 제한한다. 실제 판륜·접합선·교련을 영상에서 분할한 결과가 아니며, 경계 상자 안에 있다는 검사로 원본 판엽과의 일치나 주변 조직과의 무교차가 입증되지는 않는다.

전방 개방 신호는 각 판막의 같은 기록 주기 최고 전방 유량을 기준으로 정한다.

```text
forwardOpen = sqrt(clamp(Q / Q_peak, 0, 1))  if Q > 0 and P_upstream − P_downstream > 0
              0                             otherwise
graphic hinge angle = forwardOpen × 0.44π
```

최고 개방 각도와 제곱근 변환은 표시 설계값이다. 개방은 같은 판막의 한 주기 내 시점을 비교하기 위한 정규화이므로, 두 시나리오의 개방 크기를 비교해 유효 판구 면적이나 협착 중증도를 추정할 수 없다. 대동맥판 협착 시나리오에는 별도 고정 개방 제한을 만들지 않았으며, 계산된 압력차·유량의 변화가 유지된다. 이 모델에는 판막 관성·폐쇄 부피가 없으므로 독립적인 개폐 지연이나 유량 0에서 계속 열리는 동작도 추가하지 않는다.

승모판 역류 시나리오에서는 `Q_MV < 0`이고 역압력차가 존재할 때만 작은 접합 틈을 표시한다. 틈의 반경 비율은 기전 강도 `s > 0`에서 `0.035 + 0.13s`이고, `s = 0`에서는 0이다. 이는 누출을 구별하기 위한 도식 크기이며 역류 구멍 면적·실측 틈·역류량으로 보정된 값이 아니다. 음수 유량이 커져도 정상 전방 개방으로 바뀌지 않는다. 전방 충만 시에는 일반 전방 개방 함수를 사용한다.

## 상호작용 검수 계약

`src/App.tsx`는 현재 재생 프레임을 React 상태 `{ index, cycle, result }` 하나로 커밋한다. 심장·판막·그래프는 그 `index`의 샘플을 쓰고, 입자의 누적 유량 시간도 같은 스냅샷에서 계산한 숫자 `elapsedSeconds = cycle × period + sample.time`으로 전달한다. 이전 live ref 방식처럼 React의 다음 샘플 커밋 전에 입자 시간만 먼저 갱신되는 경로를 제거했다. 새 결과에서는 기존 결과의 주기 수를 버리고, 스크럽은 주기 수를 0으로 만든다. 이는 렌더링 동기화 장치이며 별도의 생리 시간 모델을 추가한 것이 아니다.

1. 전역 재생·일시정지와 속도는 심장·판막·입자·그래프에 함께 적용한다. 스크럽하면 즉시 해당 샘플로 이동한다.
2. 일시정지 중 재렌더링, 카메라 이동 또는 시간이 지나도 심장과 판막 자세가 바뀌지 않는다. 같은 시점으로 돌아오면 같은 자세를 만든다.
3. 혈류 표시를 꺼도 심장·판막 움직임은 켜진 상태에서 재생된다. 판막 분리·확대에서도 해당 판막의 개폐를 관찰할 수 있다.
4. 구조 숨김, 선택, 불투명도, 절단, 회전·확대, 초기화는 움직이는 구조에도 작동한다. 움직임이 카메라를 계속 재설정하지 않는다.
5. 모션 끄기는 원본을 복원하고, 다시 켜면 현재 선택 시점의 자세를 적용한다. 새 실험 대기나 해석 범위 오류에서 이전 실험 움직임을 계속 보여주지 않는다.
6. 경로와 표면을 함께 움직여도 그것만으로 내강 포함이나 충돌 회피를 검증한 것으로 보지 않는다. 분리된 메시와 판엽의 교차·틈은 별도 검수 대상이다.

## 검증 상태
